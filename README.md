# Theoria Games

*Fragments of worlds, preserved in code.*

Theoria Games is not a traditional game collection.
It is an archive of interactive atmospheres, symbolic spaces, forgotten structures, and experimental worlds built through software.

The name **Theoria** comes from the Greek θεωρία — contemplation, perception, the act of deeply observing.
That idea exists at the center of every project in this repository.

These games are not designed only to be played.
They are designed to be entered.

Inside this library are:

* silent cities
* fractured narratives
* symbolic landscapes
* strange mechanics
* interactive rituals
* unfinished myths hidden inside systems

Some projects are small.
Some are experimental.
Some may feel incomplete by design.

The purpose is not perfection.
The purpose is atmosphere, identity, and presence.

## Philosophy

Theoria Games explores the space between:

* game and artwork
* system and myth
* interaction and contemplation

Every project attempts to leave a distinct emotional or symbolic imprint rather than simply provide progression, competition, or distraction.

## Vision

To build a library of digital worlds that feel ancient, reflective, and strangely alive.
Not mass-produced entertainment, but interactive works with memory, texture, and atmosphere.
